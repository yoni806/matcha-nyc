# 🍵 KISSA MATCHA NYC

> *A sleek, minimalist New York style matcha bar showcase website.*

Live Concept: Ceremonial Japanese single-origin matcha reimagined for Downtown Manhattan (SoHo / Nolita & West Village).

---

## 📍 Sanctuaries featured
- **SoHo / Nolita**: 42 Prince St, New York, NY 10012
- **West Village**: 182 Waverly Pl, New York, NY 10014

## ✨ Features
- Modern, clean Japanese-Scandinavian typography (Playfair / Cormorant Garamond & Plus Jakarta Sans)
- Earthy ceremonial matcha palette with rich warm neutrals
- Interactive signature drink & artisanal pastry menu
- Responsive layout (mobile, tablet & desktop)
- Farm-to-cup heritage storytelling from Uji & Kagoshima to NYC

## 🚀 How to activate GitHub Pages (Free Hosting)
1. Go to your repository settings: [Repository Settings](https://github.com/yoni806/matcha-nyc/settings/pages)
2. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/ (root)**, then click **Save**.
4. Your website will be live in 1-2 minutes at:  
   👉 **`https://yoni806.github.io/matcha-nyc/`**
